
# Sorriso & Saúde

Site institucional desenvolvido para a **Sorriso & Saúde**, uma clínica odontológica fictícia.

O projeto tem como objetivo apresentar a clínica, seus tratamentos e profissionais, proporcionando uma experiência de navegação intuitiva e facilitando o contato de potenciais pacientes.


##  Funcionalidades

- **Página inicial:** apresentação da clínica e chamada para agendamento.
- **Sobre a clínica:** seção institucional com carrossel de imagens.
- **Tratamentos:** apresentação dos serviços odontológicos, com modal para exibição de informações adicionais.
- **Nossa equipe:** apresentação dos profissionais por meio de um carrossel interativo.
- **Navegação:** menu com acesso às diferentes seções do site.
- **Contato:** informações de contato e opções para iniciar o agendamento via WhatsApp.

## Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização, layout e responsividade.
- **JavaScript:** implementação das interações e funcionalidades dinâmicas.

## Como executar o projeto

Não é necessário instalar dependências ou configurar um ambiente de backend.

1. Clone o repositório:

```bash
git clone https://github.com/enzofmolina/sorriso-e-saude.git
```

2. Acesse a pasta do projeto:

```bash
cd sorriso-e-saude
```

3. Abra o arquivo `index.html` no navegador.

## Sobre o projeto

As informações sobre a clínica, os profissionais e os contatos são fictícias e utilizadas exclusivamente para fins demonstrativos.
